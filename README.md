# 🚗💸 Car Price & Performance Analysis 🔍⚙️

Welcome to the **Car Price and Performance Analysis** project!  
In this project, we dive into a dataset of cars and transform raw data into insights using **Label Encoding**, **Feature Scaling**, and a custom **Performance Index**. Buckle up! 🏎️💨

---

## 🎯 Project Objective

The main goals of this project are:

✅ Encode car brands based on average price  
✅ Scale numerical features like Horsepower & Fuel Efficiency  
✅ Create a new metric: **Performance Index**  
✅ Present clean, processed data for analysis or modeling

---

## 📊 Dataset Overview

Each car entry contains the following details:

- 🚘 **Brand** (e.g., Toyota, BMW)
- 💰 **Price** (in INR)
- 🏇 **Horsepower**
- ⛽ **Fuel Efficiency** (mpg)

---

## 🧠 What You'll Learn

This project will teach you:

🧾 **Label Encoding**: Encode brands so that more expensive brands get higher values  
📏 **Min-Max Scaling**: Normalize all numeric columns to the range [0, 1]  
🔢 **Performance Index**: Combine horsepower & fuel efficiency to calculate a smart performance score  
📈 **Final Output Table**: See all your results in a tidy table
